TravelSplit V2.4 PWA 修正版

請將此 ZIP 解壓縮後的 index.html、manifest.webmanifest、sw.js、icon-192.png、icon-512.png 全部上傳到 GitHub 儲存庫根目錄，覆蓋同名檔案。不要上傳 ZIP 本身。

此版本修正圖示路徑與離線快取清單，保留原有帳目資料格式。更新後等候 GitHub Pages 部署，再用 Chrome 開啟網站測試安裝。

注意：GitHub Pages 上的個人帳目資料存在手機瀏覽器 localStorage，更新程式不應清除網站資料；重要資料請先匯出 JSON。
